# Cover Lettering

The cover and back-cover title use a local WOFF2 subset of FandolKai-Regular,
containing only the four Chinese title characters, for traditional Kai lettering.
Cover initials and date use a local WOFF2 subset of Qwitcher Grypen.
Fandol uses GPLv3 with a font exception; Qwitcher Grypen uses SIL OFL 1.1.
The original license files and Fandol's package README are included here.

- Fandol: https://ctan.org/pkg/fandol
- Original Fandol fonts: https://mirrors.ctan.org/fonts/fandol.zip
- Qwitcher Grypen: https://github.com/google/fonts/tree/main/ofl/qwitchergrypen

Generated with fontTools subset and Brotli. No remote fonts are requested
while reading the album.
